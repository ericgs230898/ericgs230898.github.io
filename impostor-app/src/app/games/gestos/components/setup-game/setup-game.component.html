Configuración del Juego - Gestos

🎲 ¿Cómo jugar?

  • Dos equipos compiten alternando turnos
  • Equipo 1 juega las rondas impares (1, 3, 5...)
  • Equipo 2 juega las rondas pares (2, 4, 6...)
  • Cada ronda: 4 tarjetas con 2 palabras cada una
  • Representa las palabras con gestos (sin hablar)
  • Desliza hacia abajo cuando adivinen la palabra
  • ¡Gana puntos según la dificultad!
